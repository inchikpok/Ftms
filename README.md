# Treadmill Control

Android-приложение для управления беговой дорожкой по стандарту **FTMS** через Bluetooth Low Energy (BLE). Работает **полностью офлайн** — разрешение `INTERNET` намеренно не запрашивается.

Поддерживает нагрудный пульсометр, авторегулировку скорости по пульсу (AutoHR), голосовые подсказки (TTS), профили спортсменов, генератор тренировок, автоопределение возможностей железа, работу в фоне (Foreground Service), резервное копирование данных.

Репозиторий **публичный**. Это снимает лимиты GitHub Actions на минуты и хранилище — сборки идут без ограничений, APK раздаётся через **Releases**.

## Возможности

### Управление дорожкой

- Подключение по стандартному профилю **FTMS** (Service `0x1826`).
- Чтение данных в реальном времени: скорость, наклон, дистанция, калории, время.
- Управление скоростью (шаг из настроек) и наклоном (шаг 1%).
- Старт / Пауза / **Стоп с подтверждением удержанием** (0.8 сек, круговой прогресс, вибро-отклик).
- Показ **текущего сегмента программы** на главном экране (`Сегмент 4/12 · Подъём · ПАУЗА`).
- Автопауза при потере связи — время и дистанция не накручиваются.

### Пульсометр и зоны

- Стандарт **Heart Rate Service** (`0x180D`), одновременное подключение к дорожке и HR.
- График пульса в реальном времени с целевой линией.
- **Точные пульсовые зоны**: реальная кривая пульса (каждые 5 сек) в БД, зоны Z1–Z5 по фактическим данным.
- Для старых записей — аппроксимация с пометкой «≈».
- Мини-график (sparkline) в раскрытой карточке журнала.

### Автоматическая регулировка скорости по пульсу (AutoHR)

- Два режима: целевой пульс или зона (мин–макс).
- Настраивается: цель, допуски X/Y, интервал, шаг.
- НЕ работает во время программы.
- Учитывает ИМТ, вес, пол.
- Безопасность: не поднимает со стопа, останавливается при потере дорожки.

### Тренировочные программы

- Создание интервальных программ: время / скорость / наклон на сегмент.
- **Шаблоны** (полностью локализованы): Интервалы 4×3 мин, Пирамида, Горки 6×1 @ 6%, Fartlek 20 мин.
- Шаблоны автоматически **clamp'ятся по лимитам** скорости и наклона из настроек.
- Редактор сегментов: ↑↓, ⎘, 🗑, авто-повтор при удержании +/-, ввод времени ММ:СС.
- Поиск, сортировка, дублирование.
- **Импорт / экспорт JSON** (snake_case, см. раздел ниже). При превышении лимитов — предупреждение, не блокировка.
- **Генератор тренировок** («Волшебная палочка») по ИМТ, полу, возрасту, уровню, цели, длительности, интенсивности.
- Хранение в **Room (SQLite)** с поддержкой миграций.

### Экран тренировки

- Прогресс программы (сегмент N/M, остаток, общий %).
- Управление скоростью и наклоном прямо во время тренировки.
- Пауза / Продолжить — программа продолжается с того же места.
- Автопауза при потере связи.
- По завершении «Стоп» → «Готово», прогресс сохранён.

### Журнал и статистика

- История всех тренировок: дата, программа, время, км, калории, пульс.
- Раскрывающиеся карточки: базовые метрики, sparkline пульса, зоны.
- **Статистика**: сводка, средний/макс/лучший средний пульс, тренд (↓/↑), график среднего пульса, зоны.
- Кнопка **ℹ️** — пояснение к статистике.
- **Демо-данные**: добавляются к существующим записям (с префиксом `(demo)`), **не стирают** реальную историю. Есть диалог подтверждения.

### Резервная копия

- **Экспорт** в ZIP через SAF: программы, журнал, профили, настройки.
- **Восстановление** из ZIP с превью манифеста.
- **Атомарное восстановление**: при сбое любого шага старые данные возвращаются из `.bak`.
- **Блокировка** восстановления при активной тренировке.
- Авто-перезапуск после восстановления.
- SAF без разрешений.

### Уведомление в шторке

- Foreground Service с плашкой: сегмент, скорость, пульс, время, признак ПАУЗА.
- Кнопки **Пауза / Продолжить** и **Стоп**.

### Интерфейс

- **Локализация RU + EN** через системные настройки.
- Светлая / тёмная / системная тема.
- Свайп между 4 вкладками.
- `RollingText` — плавная анимация чисел.
- Плотный компактный дизайн.

### Отладка

- Экран **Debug** с полным BLE-логом.
- Отправка hex-команд, справочник, конструктор.
- Фильтры **FTMS** (кадры 2ACD) и **UI** (тапы/свайпы) — оба по умолчанию скрыты, но **в файл пишутся всегда**.
- Сохранение лога в `.txt`.

## Установка

### Вариант 1. APK из GitHub Releases
1. Откройте репозиторий → вкладка **Releases** (справа на главной).
2. Выберите последний релиз → скачайте `.apk`.
3. Откройте на телефоне → разрешите установку из неизвестных источников.

Артефакты в Actions тоже есть, но живут 1 день (для раздачи используйте Releases).

### Вариант 2. Локальная сборка
JDK 17 и Gradle 8.6+:

    gradle assembleDebug
    # APK: app/build/outputs/apk/debug/app-debug.apk

Или откройте в **Android Studio Hedgehog+**.

## Обновление без удаления

1. **Перед пушем** увеличьте `versionCode` в `app/build.gradle.kts` (в CI делается автоматически):
       versionCode = 8
       versionName = "1.8"
2. Push → дождитесь сборки → скачайте APK.
3. Откройте APK → Android покажет **«Обновить»**.

Удаление требуется только если не увеличили `versionCode` или подпись сменилась.

> С 2.3.1 данные можно **бэкапить и восстанавливать** через Настройки → Данные.

## Использование

### Подключение дорожки
1. Включите дорожку, вставьте ключ.
2. Откройте приложение. При **первом запуске** приложение спросит только уведомления (Android 13+).
3. Нажмите **«Подкл.»** на блоке «Дорожка» — **в этот момент** запросятся BLE-разрешения (Android 12+) или Location (Android < 12).
4. Выберите устройство `FS-…`, `FitShow…` или любое с FTMS.
5. Кнопка ℹ️ → диалог возможностей.

### Подключение пульсометра
1. Наденьте датчик, смочите электроды.
2. Блок «Пульсометр» → «Подкл.».
3. Выберите устройство Heart Rate.

### Ручное управление
- Плитки Скорость / Наклон с `−` / `+`. У наклона — «Сбросить».
- Старт / Пауза / **Зажмите Стоп на 0.8 сек**.

### Тренировка по программе
1. Программы → Создать → шаблон или «с нуля».
2. Отредактируйте сегменты.
3. Сохраните → ▶️ на карточке.
4. Вернуться на главную можно — текущий сегмент виден.

### Автопульс
1. Switch «Автопульс» на главном.
2. Настроить → цель/зона, X, Y, интервал, шаг.
3. При отклонении пульса приложение плавно меняет скорость.

### Работа в фоне
1. Сверните приложение.
2. В шторке — метрики и кнопки Пауза / Стоп.

### Резервная копия
1. Настройки → Данные → Экспорт резервной копии → выберите папку.
2. Для восстановления — Настройки → Данные → Восстановление из копии → ZIP.
3. Приложение покажет превью, подтвердите.
4. **Восстановление блокируется при активной тренировке**.
5. Приложение перезапустится автоматически. Старые данные можно откатить из `.bak` вручную, если что-то пойдёт не так (но обычно всё проходит штатно).

### Сохранение лога
1. Настройки → О приложении → Debug.
2. Воспроизведите проблему.
3. 💾 Сохранить → выберите папку.

## Формат JSON-программ

**Проверено на реальном экспорте.** Поля **snake_case**, double **всегда с точкой**.

Полный пример (5 интервалов по 2 минуты с отдыхом 1 минута, 25 мин):

    {
        "name": "Интервальная тренировка 5×2 мин",
        "description": "5 интервалов по 2 минуты с отдыхом 1 минута",
        "segments": [
            { "duration_sec": 300, "speed_kmh": 5.0,  "incline_percent": 0.0, "name": "Разминка" },
            { "duration_sec": 120, "speed_kmh": 10.0, "incline_percent": 0.0, "name": "Интервал 1" },
            { "duration_sec": 60,  "speed_kmh": 6.0,  "incline_percent": 0.0, "name": "Отдых 1" },
            { "duration_sec": 120, "speed_kmh": 10.0, "incline_percent": 0.0, "name": "Интервал 2" },
            { "duration_sec": 60,  "speed_kmh": 6.0,  "incline_percent": 0.0, "name": "Отдых 2" },
            { "duration_sec": 120, "speed_kmh": 10.0, "incline_percent": 0.0, "name": "Интервал 3" },
            { "duration_sec": 60,  "speed_kmh": 6.0,  "incline_percent": 0.0, "name": "Отдых 3" },
            { "duration_sec": 120, "speed_kmh": 10.0, "incline_percent": 0.0, "name": "Интервал 4" },
            { "duration_sec": 60,  "speed_kmh": 6.0,  "incline_percent": 0.0, "name": "Отдых 4" },
            { "duration_sec": 120, "speed_kmh": 10.0, "incline_percent": 0.0, "name": "Интервал 5" },
            { "duration_sec": 300, "speed_kmh": 4.0,  "incline_percent": 0.0, "name": "Заминка" }
        ]
    }

**Поля:**
- `name` (String) — название программы.
- `description` (String) — описание.
- `segments` (Array) — минимум 1.
- `segments[].duration_sec` (Int) > 0.
- `segments[].speed_kmh` (Double) > 0, **с точкой** (`5.0`, `10.5`).
- `segments[].incline_percent` (Double), **с точкой** (`0.0`, `1.0`, `1.87`). Никогда `0`, `1`.
- `segments[].name` (String).

**Ограничения:**
- UTF-8 без BOM, без комментариев (`//`, `#`), без висячих запятых.
- Регистр имён полей строгий.
- `ignoreUnknownKeys = true` → лишние поля не ломают импорт, но не сохраняются.
- Если сегмент превышает `maxSpeedKmh` / `maxInclinePercent` из настроек — импорт **не блокируется**, но показывается предупреждение.

**Частые ошибки:**
- `durationSec` / `speedKmh` / `inclinePercent` (camelCase) → не импортируется.
- `"incline_percent": 1` (Int) → может упасть.
- Smart quotes → не парсится.
- BOM → парсер видит мусор перед `{`.
- Комментарии → JSON не поддерживает.

**Эталон:** «Программы → ⋮ → Экспорт JSON».

**MIME-фильтр SAF:** `arrayOf("application/json", "text/plain", "*/*")`.

## Совместимые дорожки

Приложение увидит устройства с именем `FS-…`, `FitShow…` или сервисом FTMS `0x1826`.

**Совместимы** (проверено/ожидается): UNixFit, Kingsmith, Urevo, WalkingPad, Xiaomi WalkingPad, FitPlus, Sportstech, Horizon, Bowflex, Sole, некоторые NordicTrack, некоторые Domyos.

**Не совместимы:** Peloton, Technogym — закрытые протоколы; NordicTrack с iFit без FTMS; старые без BLE.

## Технические детали

### Стек
- Kotlin 1.9.22, JVM target 17.
- Jetpack Compose (BOM 2024.02.00, Material 3 **без** MenuAnchorType).
- MVVM + StateFlow + `TreadmillSession` + Foreground Service.
- Room 2.6.1 (БД v2, миграция 1→2: `hrSamples`).
- kotlinx.serialization 1.6.3.
- android.bluetooth.le, java.util.zip (без сторонних библиотек).
- Gradle 8.6, AGP 8.2.2, KSP 1.9.22-1.0.17.

### SDK
- min: API 21 (Android 5.0).
- target / compile: API 34.

### Разрешения
- `BLUETOOTH_SCAN`, `BLUETOOTH_CONNECT` (Android 12+).
- `BLUETOOTH`, `BLUETOOTH_ADMIN` (до Android 12).
- `ACCESS_FINE_LOCATION` (сканирование BLE до Android 12).
- `POST_NOTIFICATIONS` (Android 13+).
- `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_CONNECTED_DEVICE`.
- **`INTERNET` отсутствует намеренно.**
- `WRITE_EXTERNAL_STORAGE` / `READ_EXTERNAL_STORAGE` **не нужны** (всё через SAF).

### Особенности прошивки UNixFit-990x (и некоторых других)
- Пульт дорожки и BLE работают независимо; при старте с пульта команды приложения игнорируются.
- Belt принимает только **целые проценты** наклона.
- Команды иногда теряются → дублируются (интервал ~60 мс).
- Control Point не отвечает, но выполняет команды.
- **Stop `08 01` работает** и сбрасывает таймер. `02 00 00` останавливает мотор, но **не сбрасывает таймер** — не использовать.
- После потери связи дорожка может «залипнуть». Корректный `disconnect → wait → refresh() → close()` частично лечит.

## Конфиденциальность

- В `AndroidManifest.xml` **отсутствует** `INTERNET`.
- Все данные хранятся локально (Room/SQLite + SharedPreferences).
- Резервная копия — локальный ZIP (пользователь сам выбирает папку через SAF).
- Никакие данные никуда не отправляются.

**Внимание:** репозиторий публичный, keystore `treadmill.keystore` и пароль
`treadmill123` в `build.gradle.kts` видны всем. Для личного использования это
приемлемо, но любой может собрать «обновление» с вашим ключом. При публикации
в Google Play — переделать на GitHub Secrets.

## Диагностика проблем

### Дорожка не появляется в сканере
- Bluetooth включён, разрешения даны (запрашиваются при «Подкл.»).
- Дорожка включена, не подключена к другому телефону.
- Подождите 5 секунд после отключения (кулдаун сканирования).
- Старые дорожки без BLE невидимы.

### Команды не выполняются
- При старте с пульта дорожка может игнорировать BLE.
- Debug → отвечает ли дорожка (`<-`) на команды (`->`).

### Наклон «через раз»
- Особенность прошивки UNixFit-990x.
- Увеличьте `maxAttempts` в `FTMSProtocol.kt`.

### Пульсометр не подключается
- Смочите электроды.
- Проверьте сервис `0x180D`.

### На Android 14+ сервис не запускается
- В манифесте есть `foregroundServiceType="connectedDevice"` и
  `FOREGROUND_SERVICE_CONNECTED_DEVICE`. Это исправлено. Если форкаете — не
  удаляйте эти строки.

### Резервная копия не восстанавливается
- ZIP должен быть создан **этим** приложением.
- Восстановление блокируется при активном сервисе.
- При ошибке скопируйте `.bak` файлы обратно вручную (атомарный откат обычно
  справляется сам, но `.bak` остаются на диске до успеха).

### JSON-программа не импортируется
- Проверьте **snake_case** (`duration_sec`, `speed_kmh`, `incline_percent`).
- Double с точкой (`1.0`, `0.0`, `5.5`), не `1`, `0`.
- UTF-8 без BOM, прямые кавычки, без комментариев.
- Эталон — «Программы → ⋮ → Экспорт JSON».

### Локализация не применилась
- Clean Project → Rebuild.
- Или переустановите приложение.

### Actions: `Artifact storage quota has been hit`
- Раньше было актуально для private-репо. Сейчас репо **публичный**, лимитов нет.
- Если снова появится — проверьте, не сделали ли репо private.
