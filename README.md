# Treadmill Control

Android-приложение для управления беговой дорожкой по стандарту **FTMS** через Bluetooth Low Energy (BLE). Работает **полностью офлайн** — разрешение `INTERNET` намеренно не запрашивается.

Поддерживает нагрудный пульсометр, авторегулировку скорости по пульсу (AutoHR), голосовые подсказки (TTS), профили спортсменов, генератор тренировок, автоопределение возможностей железа, работу в фоне (Foreground Service), резервное копирование данных.

---

## Возможности

### Управление дорожкой

- Подключение по стандартному профилю **FTMS** (Service `0x1826`).
- Чтение данных в реальном времени: **скорость, наклон, дистанция, калории, время**.
- Управление скоростью (шаг из настроек, по умолчанию 0.5 км/ч).
- Управление наклоном (шаг 1%).
- Старт / Пауза / **Стоп с подтверждением удержанием** (0.8 сек, с круговым прогрессом и вибро-откликом) — защита от случайного нажатия в кармане.
- Показ **текущего сегмента программы** прямо на главном экране (`Сегмент 4/12 · Подъём · ПАУЗА`).
- Кнопки дизейблятся, если дорожка не подключена.
- **Автопауза при потере связи** — время и дистанция не накручиваются, пока дорожка стоит.

### Пульсометр и зоны

- Подключение по стандарту **Heart Rate Service** (`0x180D`).
- Одновременное подключение к дорожке и пульсометру.
- График пульса в реальном времени с целевой линией.
- **Точные пульсовые зоны**: приложение сохраняет реальную кривую пульса за тренировку (каждые 5 секунд) в БД и строит зоны Z1–Z5 на основе фактических данных. Для старых записей используется аппроксимация с пометкой "≈".
- Мини-график пульса (sparkline) в раскрытой карточке журнала.

### Автоматическая регулировка скорости по пульсу (AutoHR)

- Два режима: **целевой пульс** или **зона (мин–макс)**.
- При превышении — плавное снижение скорости, при недостатке — повышение.
- Настраивается: цель, допуски X/Y, интервал корректировки, шаг.
- НЕ работает во время программы (чтобы не спорить с сегментами).
- Учитывает ИМТ, вес, пол.
- Безопасность: не поднимает скорость со стопа, останавливается при потере дорожки.

### Тренировочные программы

- Создание интервальных программ: время / скорость / наклон на каждый сегмент.
- **Шаблоны** (полностью локализованы): Интервалы 4×3 мин, Пирамида, Горки 6×1 @ 6%, Fartlek 20 мин.
- Редактор сегментов: ↑↓ (перемещение), ⎘ (копия), 🗑 (удалить), авто-повтор при удержании +/-, ввод времени ММ:СС (Wheel Picker).
- Поиск и сортировка (А→Я, Я→А, Сначала новые).
- Дублирование программы целиком.
- **Импорт / экспорт JSON** (формат — snake_case, см. раздел ниже).
- **Генератор тренировок** ("Волшебная палочка"): по ИМТ, полу, возрасту, уровню подготовки, цели (WEIGHT_LOSS / CARDIO / SPEED), длительности и интенсивности. Названия программ и сегментов локализованы RU/EN.
- Хранение в **Room (SQLite)** с поддержкой миграций.

### Экран тренировки

- Прогресс программы (сегмент N/M, остаток времени, общий %).
- Управление скоростью и наклоном **прямо во время тренировки**.
- Кнопка **Пауза / Продолжить** — программа продолжается с того же места.
- Автопауза при потере связи с дорожкой.
- График пульса и метрики.
- По завершении кнопка "Стоп" меняется на "Готово", прогресс сохраняется в журнал.

### Журнал и статистика

- История всех тренировок: дата, программа, время, км, калории, пульс.
- Раскрывающиеся карточки:
  - базовые метрики (время, дистанция, калории);
  - мини-график пульса (sparkline) из сохранённой кривой;
  - распределение по пульсовым зонам (мини-бар + детализация).
- **Статистика**:
  - Общая сводка (всего тренировок / часов / км / ккал);
  - Средний, максимальный, лучший средний пульс;
  - **Тренд** — сравнение первой и второй половины тренировок;
  - График **среднего** пульса по датам (кривая Безье, без фоновых зон для чистоты);
  - Пульсовые зоны суммарно по всем тренировкам.
- Кнопка **ℹ️** на вкладке "Статистика" — пояснение, какие тренировки учитываются (только с активным пульсометром).
- **Демо-данные** (14 тренировок за 10 недель) — посмотреть статистику без реальных занятий.

### Резервная копия

- **Экспорт** всех данных (программы, журнал, профили, настройки) в один **ZIP-файл** через системный SAF-пикер: можно сохранить в Downloads, на флешку (USB-MTP), в облако.
- **Восстановление** из ZIP с превью (дата, количество программ/тренировок/профилей) и подтверждением.
- **Блокировка** восстановления, если идёт тренировка или подключена дорожка (активен Foreground Service) — чтобы не потерять текущую сессию.
- После восстановления приложение **автоматически перезапускается** — новые данные гарантированно читаются в `Application.onCreate`.
- Никаких разрешений (SAF работает с API 21 без `WRITE_EXTERNAL_STORAGE`).

### Уведомление в шторке

- **Foreground Service** с плашкой:
  - заголовок — текущий сегмент программы (`Сегмент 3/12 · Подъём`);
  - тело — скорость, пульс, время, признак `ПАУЗА`;
  - две кнопки: **Пауза / Продолжить** и **Стоп**;
  - время с часами при длительности > 1 ч (`1:23:45`).

### Интерфейс

- **Локализация RU + EN** через системные настройки Android (`values/strings.xml` + `values-ru/strings.xml`).
- **Светлая / тёмная / системная тема**.
- **Навигация свайпом** между 4 вкладками (Главная, Программы, Журнал, Настройки).
- **Прокрутка чисел** (`RollingText`) — плавная анимация смены значений.
- Имя подключённой дорожки показывается в заголовке + кнопка ℹ️ → диалог возможностей.
- Плотный компактный дизайн без "воздуха".

### Отладка

- Экран **Debug** с полным BLE-логом всех команд и ответов.
- Отправка произвольных hex-команд.
- Справочник стандартных команд (запуск, стоп, скорости, наклоны).
- **Конструктор** hex-команд.
- **Сохранение лога в файл** (`.txt`) для диагностики.

## Установка

### Вариант 1. Готовый APK из GitHub Actions

1. Откройте репозиторий → вкладка **Actions**.
2. Дождитесь зелёной галочки в workflow **Build APK**.
3. Внизу страницы — **Artifacts** → скачайте `treadmill-debug-apk` (это сам APK, без архива).
4. Откройте файл на телефоне → разрешите установку из неизвестных источников.

### Вариант 2. Локальная сборка

Требуется **JDK 17** и **Gradle 8.6+**:

    gradle assembleDebug
    # APK: app/build/outputs/apk/debug/app-debug.apk

Или откройте проект в **Android Studio Hedgehog+**.

## Обновление без удаления

Чтобы обновить приложение, сохранив программы, настройки и журнал:

1. **Перед пушем** увеличьте `versionCode` в `app/build.gradle.kts`:

       versionCode = 8   // было 7
       versionName = "1.8"

2. Push → дождитесь сборки → скачайте APK.
3. Откройте APK на телефоне → Android покажет **"Обновить"**.
4. Все данные сохранятся.

Удаление требуется только если:

- не увеличили `versionCode`,
- предыдущая версия была подписана другим ключом.

> С версии 2.3.1 данные можно **бэкапить и восстанавливать** через Настройки → Данные — без переустановки.

## Использование

### Подключение дорожки

1. Включите дорожку, вставьте аварийный ключ.
2. Откройте приложение, разрешите доступ к Bluetooth (Android 12+) и уведомлениям (Android 13+).
3. На главном экране → блок **"Дорожка"** → **"Подкл."**.
4. Выберите устройство `FS-…`, `FitShow…` или любое с FTMS-сервисом.
5. После подключения кнопка ℹ️ → диалог возможностей (скорость, наклон, поддержка пульса).

### Подключение пульсометра

1. Наденьте нагрудный датчик, смочите электроды.
2. Блок **"Пульсометр"** → **"Подкл."**.
3. Выберите устройство Heart Rate.

### Ручное управление

- Плитки **Скорость** и **Наклон** с кнопками `−` / `+`.
- У наклона — **"Сбросить"** (возвращает 0%).
- Кнопка **"Старт"** — запуск.
- Кнопка **"Пауза / Продолжить"** — пауза и возобновление.
- **Зажмите "Стоп"** на 0.8 сек — остановка (с круговым прогрессом и вибро).

### Тренировка по программе

1. Вкладка **Программы** → **Создать** → выберите шаблон или "с нуля".
2. Отредактируйте сегменты или добавьте новые.
3. Сохраните → **▶️** на карточке.
4. Откроется экран тренировки. Управление и пауза — там же.
5. Можно вернуться на главную — тренировка продолжается, текущий сегмент виден на главном экране.

### Автопульс

1. Включите Switch **"Автопульс"** на главном экране.
2. **Настроить** → настройте цель/зону, X, Y, интервал, шаг.
3. При отклонении пульса приложение плавно меняет скорость.

### Работа в фоне

1. Сверните приложение во время тренировки.
2. В шторке уведомлений появятся метрики и кнопки **Пауза** / **Стоп**.
3. Управление доступно без открытия приложения.

### Резервная копия и восстановление

1. **Настройки → Данные → Экспорт резервной копии** → выберите папку
   (Downloads, флешка, облако). Приложение сохранит `treadmill-backup-YYYY-MM-DD-HHmmss.zip`.
2. Для восстановления: **Настройки → Данные → Восстановление из копии** → выберите ZIP.
3. Приложение покажет превью (дата, программы, тренировки, профили). Подтвердите.
4. **Внимание:** восстановление блокируется, если активна тренировка. Сначала остановите
   тренировку и отключите дорожку.
5. После восстановления приложение перезапустится автоматически — не пугайтесь.

### Сохранение лога для диагностики

1. Настройки → Дополнительно → **Debug**.
2. Воспроизведите проблему.
3. Кнопка 💾 **Сохранить** → выберите папку → сохранится `.txt`.

## Формат JSON-программ

**Проверено на реальном экспорте из приложения (октябрь 2026).** Поля — **snake_case**, не camelCase, как ошибочно писали до v2.3.2. Все числовые поля с плавающей точкой — **только с точкой**, никогда целые.

Полный пример (5 интервалов по 2 минуты с отдыхом 1 минута, итого 25 мин):

    {
        "name": "Интервальная тренировка 5×2 мин",
        "description": "5 интервалов по 2 минуты с отдыхом 1 минута",
        "segments": [
            { "duration_sec": 300, "speed_kmh": 5.0,  "incline_percent": 0.0, "name": "Разминка" },
            { "duration_sec": 120, "speed_kmh": 10.0, "incline_percent": 0.0, "name": "Интервал 1" },
            { "duration_sec": 60,  "speed_kmh": 6.0,  "incline_percent": 0.0, "name": "Отдых 1" },
            { "duration_sec": 120, "speed_kmh": 10.0, "incline_percent": 0.0, "name": "Интервал 2" },
            { "duration_sec": 60,  "speed_kmh": 6.0,  "incline_percent": 0.0, "name": "Отдых 2" },
            { "duration_sec": 120, "speed_kmh": 10.0, "incline_percent": 0.0, "name": "Интервал 3" },
            { "duration_sec": 60,  "speed_kmh": 6.0,  "incline_percent": 0.0, "name": "Отдых 3" },
            { "duration_sec": 120, "speed_kmh": 10.0, "incline_percent": 0.0, "name": "Интервал 4" },
            { "duration_sec": 60,  "speed_kmh": 6.0,  "incline_percent": 0.0, "name": "Отдых 4" },
            { "duration_sec": 120, "speed_kmh": 10.0, "incline_percent": 0.0, "name": "Интервал 5" },
            { "duration_sec": 300, "speed_kmh": 4.0,  "incline_percent": 0.0, "name": "Заминка" }
        ]
    }

**Поля:**

- `name` — строка, название программы (обязательно, не пустое)
- `description` — строка, описание (может быть пустым)
- `segments` — массив сегментов (минимум 1)
- `segments[].duration_sec` — **int**, длительность в секундах (> 0)
- `segments[].speed_kmh` — **double**, скорость км/ч (> 0). **Всегда с точкой**: `5.0`, `10.5`, `0.5`
- `segments[].incline_percent` — **double**, процент наклона. **Всегда с точкой**: `0.0`, `1.0`, `1.87` (даже ноль — `0.0`, не `0`)
- `segments[].name` — строка, название сегмента

**Ограничения:**

- Файл UTF-8 **без BOM**, без комментариев (`//`, `#`), без висячих запятых
- Порядок полей внутри объекта не важен, регистр имён — **строгий**
- `ignoreUnknownKeys = true` в парсере → **лишние поля не ломают импорт**, но и не сохраняются
- `duration_sec` обязателен и должен быть **> 0**, `speed_kmh` — **> 0** (иначе импорт отклонится)

**Частые ошибки:**

- `durationSec` / `speedKmh` / `inclinePercent` (camelCase) → **не импортируется**, парсер не находит обязательные поля
- `"incline_percent": 1` (целое) → может упасть, пиши `1.0`
- Smart quotes (`"…"` вместо `"…"`) → файл не парсится, проверь в редакторе
- BOM в начале файла (`EF BB BF`) → парсер видит невидимый символ перед `{`
- Комментарии `//` или `#` → JSON не поддерживает, парсер упадёт

**Как получить эталон:** в приложении → любая программа → ⋮ → «Экспорт JSON». Файл будет гарантированно валидным.

**MIME-фильтр SAF:** `arrayOf("application/json", "text/plain", "*/*")` — файл с любым расширением будет виден в пикере. Проблема может быть только в содержимом.

## Совместимые дорожки

Приложение увидит устройства, у которых:

- имя начинается на **`FS-`** (например, `FS-E629DD`),
- имя содержит **`fitshow`**,
- или в рекламном BLE-пакете есть сервис **FTMS** (`0x1826`).

**Совместимы** (проверено или ожидается): UNixFit, Kingsmith, Urevo, WalkingPad, Xiaomi WalkingPad, FitPlus, Sportstech, Horizon, Bowflex, Sole, некоторые модели NordicTrack, некоторые Domyos.

**Не совместимы:** Peloton, Technogym — закрытые протоколы; модели NordicTrack с iFit без FTMS; старые дорожки без BLE.

## Технические детали

### Стек

- **Kotlin** 1.9.22, JVM target 17
- **Jetpack Compose** (BOM 2024.02.00, Material 3 БЕЗ MenuAnchorType)
- **MVVM** + StateFlow + `TreadmillSession` (ядро) + Foreground Service
- **Room** 2.6.1 (версия БД 2, миграция 1→2: `hrSamples`)
- **kotlinx.serialization** 1.6.3
- **android.bluetooth.le** (без сторонних BLE-библиотек)
- **java.util.zip** (для резервного копирования, без зависимостей)
- **Gradle** 8.6, AGP 8.2.2, KSP 1.9.22-1.0.17

### SDK

- min: API 21 (Android 5.0)
- target / compile: API 34

### Разрешения

- `BLUETOOTH_SCAN`, `BLUETOOTH_CONNECT` (Android 12+)
- `BLUETOOTH`, `BLUETOOTH_ADMIN` (до Android 12)
- `ACCESS_FINE_LOCATION` (для сканирования BLE на Android < 12)
- `POST_NOTIFICATIONS` (Android 13+)
- `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_CONNECTED_DEVICE`
- **`INTERNET` — отсутствует намеренно.**
- **`WRITE_EXTERNAL_STORAGE` / `READ_EXTERNAL_STORAGE` — не нужны.** Резервное копирование и экспорт логов работают через SAF.

### Особенности прошивки UNixFit-990x (и некоторых других)

- Пульт дорожки и BLE работают независимо; **при старте с пульта команды приложения игнорируются**.
- Belt принимает только **целые проценты** наклона (0.5% игнорируется).
- Команды иногда теряются → дублируются (интервал ~60 мс).
- Control Point не отвечает на команды, но выполняет их.
- **Stop `08 01` работает** и сбрасывает таймер. Старая команда `02 00 00` останавливает мотор, но **не сбрасывает таймер** — не использовать.
- После потери связи дорожка может «залипнуть» в состоянии «подключён». Корректный `disconnect → wait callback → refresh() → close()` частично лечит; полное лечение — выключить/включить питание дорожки.

## Конфиденциальность

Приложение работает **полностью офлайн**:

- В `AndroidManifest.xml` **отсутствует** `android.permission.INTERNET`.
- Все данные (программы, настройки, журнал, профили) хранятся локально в Room/SQLite и SharedPreferences.
- Резервная копия — локальный ZIP, который **пользователь сам** кладёт в выбранную папку (в т.ч. в облако через SAF, если захочет).
- Никакие данные никуда не отправляются.

## Диагностика проблем

### Дорожка не появляется в сканере

- Убедитесь, что Bluetooth включён и разрешения даны.
- Дорожка должна быть включена и не подключена к другому телефону.
- После отключения подождите 5 секунд — это нормальный кулдаун сканирования.
- Старые дорожки без BLE (только пульт) физически невидимы.

### Команды не выполняются

- Проверьте: при старте с пульта дорожка может игнорировать BLE-команды.
- Откройте **Debug** и посмотрите, отвечает ли дорожка (`<-`) на команды (`->`).

### Наклон работает "через раз"

- Это особенность прошивки UNixFit-990x. Приложение дублирует команды и ждёт подтверждения.
- Увеличьте `maxAttempts` в `FTMSProtocol.kt` (по умолчанию 2).

### Пульсометр не подключается

- Некоторые пульсометры требуют смачивания электродов.
- Проверьте, что у него есть сервис `0x180D`.

### Приложение падает

- Удалите старую версию и установите заново.
- Если падает регулярно — пришлите лог Debug.

### На Android 14+ сервис не запускается

- В нашем манифесте уже указаны `android:foregroundServiceType="connectedDevice"`
  и разрешение `FOREGROUND_SERVICE_CONNECTED_DEVICE` — это исправлено.
- Если вы форкаете проект и убрали эти строки — краш при старте сервиса гарантирован.

### Резервная копия не восстанавливается

- Файл должен быть `.zip`, созданный **этим** приложением (не переименованный и не пересобранный вручную).
- Восстановление блокируется, пока запущен Foreground Service (тренировка или подключённая дорожка). Остановите тренировку и отключите дорожку.
- Если после подтверждения приложение перезапускается и данные на месте — всё ок.
- При ошибке «Некорректный файл резервной копии» — проверьте, что ZIP не повреждён.

### JSON-программа не импортируется

- Проверьте имена полей: `duration_sec`, `speed_kmh`, `incline_percent` (**snake_case**, не camelCase).
- Все double-поля — с точкой (`1.0`, `0.0`, `5.5`). `"incline_percent": 1` может не приняться.
- Убедитесь, что файл сохранён в UTF-8 **без BOM**, с прямыми кавычками `"`.
- В файле не должно быть комментариев (`//`, `#`) — JSON их не поддерживает.
- Эталон: «Программы → ⋮ → Экспорт JSON» — этот файл точно импортируется.

### Локализация не применилась

- Сделайте **Clean Project → Rebuild** (Android кэширует ресурсы).
- Или удалите и установите приложение заново.

## Сборка через GitHub Actions

Файл `.github/workflows/build.yml` собирает APK при каждом push в `main`/`master`.
APK доступен в разделе **Actions → Artifacts** без архива (прямой `.apk`).

Кэш Gradle ускоряет повторные сборки: первая — 4–5 мин, последующие — 2–3 мин.
